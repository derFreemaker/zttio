## Documentation Conventions
- Reference: `- ref: ...`
  - in case the ref is a file path we normally assume it comes out of the windows sdk or windows driver kit (wdk)
  - special ref: `<phnt>` referes to the System Informer (formerly Process Hacker) [phnt headers](https://github.com/winsiderss/systeminformer/tree/master/phnt)
- Version: `- version: <since> - <until/...> (<ref>)`
  - a reference is only needed if not a already listed reference contains the information
